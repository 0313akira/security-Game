# ホワイトハッカー・ミッション

ホワイトハッカーになって、ソースコード・メール・SNS・設定ファイル・ログから**脆弱性（セキュリティの穴）を見つける**学習ゲームです。

## 遊び方
`index.html` をブラウザで開くだけ（インストール不要・オフラインOK）。

1. 危ないと思う行をクリックしてマーク
2. 「診断レポート提出」で答え合わせ（見つけたら +100、安全な行をマークすると減点）
3. 解説と対策コードを読み、「直し方クイズ」に挑戦（正解 +50）

## モード
| モード | 内容 |
|---|---|
| ストーリーモード | 全15ミッション。謎のハッカー集団から「まなび高校」を守る物語 |
| クイックプレイ | ランダムな5ミッション |
| 苦手克服モード | 正解率の低い題材から5ミッション |
| ステージを選ぶ | 題材を1つ選んでプレイ |
| ターミナル演習 | コマンドを打ち込んでサーバーを調査する実践モード（全5演習） |

## 難易度
| | 脆弱性の数 | ヒント | 誤検知 | 制限時間 |
|---|---|---|---|---|
| 初級 | 表示 | 無料 | -10 | なし |
| 中級 | 表示 | -50 | -30 | なし |
| 上級 | 非表示 | なし | -50 | あり（残り時間ボーナス最大+50） |

## ターミナル演習
画面の中だけで動く疑似ターミナルで、本物のホワイトハッカーのようにコマンドを打って調査します（本物のコンピューターには一切つながりません）。目標を順にクリアし、見つけた答えは `submit 答え` で報告します。`hint` でヒント、`help` でコマンド一覧、↑↓で履歴、Tabで補完。

| # | 演習 | 学べるコマンド |
|---|---|---|
| 1 | はじめてのターミナル：置き忘れたファイル | ls / ls -a / cd / cat / pwd |
| 2 | ログから攻撃者を探せ | head / grep / パイプ / wc -l |
| 3 | サーバーを偵察せよ | ping / nmap / curl / robots.txt |
| 4 | ソースコードから秘密を探せ | find / grep -r / git log / git show |
| 5 | 侵入者を追跡せよ | ログ調査 / find / 遮断・パスワード変更・報告 |

ヒントの使用回数で ★1〜3 の評価が付きます。

## 学習・記録の機能
- **ランダム出題**：各題材に2パターンの問題があり、前回と違うパターンが出ます。クイズも複数から出題され、選択肢の順番は毎回シャッフル。
- **学習テキスト**：15題材の解説（どんなもの？／具体例／何が危ない？／対策／豆知識／試験に出るポイント）。
- **試験対策・用語集**：情報セキュリティマネジメント試験・基本情報技術者試験によく出る用語の一覧と検索、10問の用語クイズ。直し方クイズにも【試験風】の問題が出ます。
- **成績・苦手リスト**：分野別・題材別の正解率と、よく見逃す脆弱性。
- **実績**：21種類。
- 効果音（右上で切り替え）。記録はブラウザに保存されます（別のブラウザには引き継がれません）。

## ファイル構成と編集のしかた
`index.html` は自動で作られるファイルです。直接編集せず、`src/` を編集してから `./build.sh` を実行してください。

| ファイル | 中身 |
|---|---|
| `src/data.js` | 問題・クイズ・学習テキスト・用語・実績などのデータ |
| `src/terminal-data.js` | ターミナル演習のデータ（仮想ファイル・目標など） |
| `src/terminal.js` | 疑似ターミナルの処理 |
| `src/app.js` | ゲームの処理 |
| `src/style.css` | 見た目 |
| `src/template.html` | 画面の骨組み |

問題を増やすときは、`src/data.js` の `TOPICS` の中の `variants` に1つ追加します。行番号は0から数えます。

> ⚠ ホワイトハッカーの約束：診断は許可されたシステムだけ。他人のシステムを勝手に調べるのは不正アクセス禁止法違反です。
