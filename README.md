# ホワイトハッカー・ミッション

ホワイトハッカーになって、ソースコード・メール・設定ファイル・ログから**脆弱性（セキュリティの穴）を見つける**学習ゲームです。授業用。

## 遊び方
`index.html` をブラウザで開くだけ（インストール不要・オフラインOK）。

1. 危ないと思う行をクリックしてマーク
2. 「診断レポート提出」で答え合わせ（正解 +100 / 誤検知 -30 / ヒント -50）
3. 解説と対策コードを読み、「直し方クイズ」に挑戦（正解 +50）
4. 全10ミッション終了でランク（S〜D）判定

## ミッション一覧
| # | テーマ | 学べること |
|---|---|---|
| 1 | ログイン画面 | SQLインジェクション |
| 2 | コメント掲示板 | XSS |
| 3 | 怪しいメール | フィッシングの見分け方 |
| 4 | 会員登録 | パスワードの安全な保存 |
| 5 | ファイルダウンロード | ディレクトリトラバーサル |
| 6 | サーバー設定 | 初期パスワード・デバッグモード・アクセス制限 |
| 7 | 成績API | 認証と認可（IDOR） |
| 8 | ping ツール | OSコマンドインジェクション |
| 9 | アプリ設定 | 秘密情報のハードコード |
| 10 | アクセスログ | 攻撃の痕跡調査・インシデント対応 |

「ステージを選ぶ」から特定のテーマだけ遊ぶこともできます。

## 学習テキスト
タイトル画面の「📖 学習テキスト」から、10の題材それぞれの解説（どんなもの？／具体例／何が危ない？／対策／豆知識）を読めます。各章から該当ミッションに直接挑戦でき、ミッションの結果画面からも「学習テキストで復習」で開けます。解説は `index.html` の `LESSONS` 配列にあります。

## 問題の追加
`index.html` の `STAGES` 配列にオブジェクトを追加するだけです（`lines` に表示行、`vulns` に脆弱性の行番号（0始まり）と解説、`quiz` にクイズ）。

> ⚠ ホワイトハッカーの約束：診断は許可されたシステムだけ。他人のシステムを勝手に調べるのは不正アクセス禁止法違反です。
